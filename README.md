# 🏠 Student Accommodation Management System

A web-based Student Accommodation Management System developed using PHP and MySQL.  
The system helps students find and book available rooms while allowing administrators to manage rooms and bookings efficiently.

## 🚀 Features

- 👨‍🎓 Student Registration & Login
- 🔐 Secure User Authentication
- 🏠 View Available Rooms
- 🔎 View Room Details
- 📅 Book Rooms
- 📋 View My Bookings
- 👨‍💼 Admin Dashboard
- ➕ Add New Rooms
- ✏️ Edit Room Details
- 🗑️ Delete Rooms
- 📊 Manage Student Bookings
- 🖼️ Room Images

## 🛠️ Technologies Used

## ⚙️ How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Create the required database in phpMyAdmin.
5. Import the project database.
6. Open the project in your browser:

http://localhost/student_accommodation/
